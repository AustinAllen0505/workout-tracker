# Workout Tracker

A simple Python console application that allows users to log and track their workouts over time. The program saves workout data to a CSV file so progress can be viewed between sessions.

## Features

- Log workouts with date, exercise, weight, sets, and reps
- View previous workout history
- Search workouts by exercise
- View personal records for each exercise
- Save and load workout data using a CSV file

## How to Run

Run the application from the terminal:

python main.py

Follow the menu prompts to log workouts, view your history, search exercises, or view personal records.
